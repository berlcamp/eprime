# DepEd Logo Assets

This folder contains logo placeholders for official documents. For production use, replace the SVG placeholders with official DepEd assets:

- **deped_header.png** (in `/public/`) – DepEd header for document letterheads
- **matatag.png** – Matatag Logo (DepEd brand)
- **bagong.png** – Bagong Pilipinas Logo
- **bayugan.png** – Bayugan City / SDO Logo

The printables use PNG files when available and fall back to the included SVG placeholders. Add your official logo files to enable proper branding on printed documents.
